# Airlines Flights Data - SQL Analizi

Hindistan iç hat uçuş verileri üzerinde yaptığım SQL pratik projesidir.

## Veri Seti
Kaggle üzerinden alınan **Airlines Flights Data** veri seti kullanılmıştır.  
Veri seti; havayolu şirketi, kalkış-varış şehirleri, uçuş süresi, bilet sınıfı ve fiyat gibi bilgileri içermektedir.

Kaynak:https://www.kaggle.com/datasets/rohitgrewal/airlines-flights-data

## Kullanılan SQL Konuları
- SELECT, WHERE, ORDER BY
- GROUP BY + HAVING
- Aggregate Fonksiyonlar (COUNT, AVG)
- CASE WHEN
- Alt Sorgu (Subquery)
- TOP

## Projede Cevaplanan Sorular
1. Hangi şehirden kaç defa uçulmuş?
2. Hangi şehre ne kadar uçulmuş?
3. Delhi → Mumbai aktarmasız uçuşlarda kalkış saatine göre ortalama süre
4. En fazla uçuş yapan havayolu şirketi
5. Ortalama bilet fiyatına göre havayolları
6. Ortalama fiyata göre havayolu kategorileri (Economy / Mid-Range / Lux-Premium)
7. Ortalama fiyattan daha pahalı biletler
8. Ortalama fiyatı genel ortalamanın üzerinde olan havayolları
9. En pahalı 5 rota
